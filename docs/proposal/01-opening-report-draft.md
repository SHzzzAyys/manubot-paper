# 开题报告正文草稿

## 一、选题背景与研究意义

刚地弓形虫是一种重要的人兽共患寄生虫，其传播控制长期以来是寄生虫学和公共卫生领域的重点问题之一。
猫科动物作为终末宿主，能够向环境排出卵囊，因此在传播链中发挥源头性作用。
相较于单纯关注中间宿主感染和组织包囊形成，针对猫开展传播阻断研究更有可能从源头降低环境污染和暴露风险。

围绕猫弓形虫疫苗的研究具有明显的 One Health 意义。
一方面，该方向可为终末宿主免疫保护机制提供新的理论认识；
另一方面，若能够获得稳定有效的减排卵囊策略，则有望在环境污染控制、家畜感染预防和人群暴露风险降低等方面发挥综合效益。

## 二、国内外研究现状

现有研究总体上可分为基础免疫认识、减毒株概念验证、黏膜免疫与亚单位疫苗探索、以及近年的 DNA 疫苗和遗传工程减毒株研究等几个阶段。
早期研究明确了肠道阶段在抗再排卵囊保护中的关键作用，并通过 T-263 等非产卵囊株证明了终末宿主传播阻断型疫苗在生物学上的可行性。
随后，rhoptry 粗抗原、rROP2 和 rGRA12 等分子平台被用于探索更加安全和标准化的免疫策略。
近年来，HAP2 KO 和 PruΔpp2a-c 等研究则提示，遗传工程减毒株仍具有较高水平传播阻断潜力。

尽管如此，当前研究仍存在评价体系不统一、保护性机制未完全阐明、长期和异源保护证据不足、以及高保护路线与高可转化路线难以兼顾等问题。

## 三、拟解决的核心问题

基于现有文献，可将本方向的核心问题概括为：

1. 哪些候选路线在猫终末宿主模型中更可能影响卵囊排出终点？
2. 现有不同技术路线的证据强度和局限性分别是什么？
3. 哪些研究空白最适合作为后续实验设计或论文研究切入点？

## 四、研究目标

本课题拟在系统梳理猫弓形虫疫苗研究现状的基础上，围绕终末宿主传播阻断这一核心问题，对不同技术路线的研究证据进行整合比较，归纳现有研究空白，并为后续课题设计提供理论依据。

如需偏实验前导型表述，可改为：

本课题拟围绕猫弓形虫疫苗的研究现状、证据分级与主要空白展开分析，明确当前候选路线在卵囊排出抑制、长期保护、异源保护和转化可行性方面的优势与不足，并据此提出后续实验研究的重点方向。

## 五、研究内容

1. 系统整理猫弓形虫疫苗相关原始研究、支撑性研究与综述文献。
2. 比较不同候选路线在免疫程序、攻毒设计、卵囊结局和证据强度方面的差异。
3. 提炼该领域在评价体系、保护机制、长期与异源保护以及转化应用方面的主要研究空白。
4. 形成可服务后续实验设计、论文写作和答辩汇报的结构化材料。

## 六、预期结果

1. 形成一篇结构完整的猫弓形虫疫苗研究综述。
2. 建立可持续更新的结构化证据库。
3. 形成用于毕业论文写作、开题汇报和答辩准备的高复用资产。
