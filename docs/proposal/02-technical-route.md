# 技术路线与实施步骤模板

## 技术路线总述

本课题拟采用“文献整合 -> 证据分级 -> 研究空白提炼 -> 写作与转化输出”的技术路线开展。

## 路径一：文献收集与筛选

1. 明确关键词和检索范围。
2. 检索直接猫模型研究、支撑性机制研究和高质量综述。
3. 按纳入标准筛选与课题相关的文献。

## 路径二：结构化证据整理

1. 提取每篇研究的免疫程序、攻毒设计、免疫学结果和卵囊终点。
2. 录入结构化证据库。
3. 对直接研究和支撑性研究进行分层管理。

## 路径三：证据分级与研究比较

1. 按 `A/B/C` 分级框架对研究证据进行整理。
2. 比较不同候选路线在保护水平、机制证据和转化可行性上的差异。
3. 形成核心表、研究矩阵和时间轴。

## 路径四：研究空白与研究设计凝练

1. 提炼评价体系、机制研究、长期保护、异源保护和转化难点等空白。
2. 形成研究问题、研究目标和创新点表述。
3. 为后续实验研究或论文撰写提供依据。

## 路径五：成果输出

1. 输出综述稿。
2. 输出结构化证据库。
3. 输出毕业论文和答辩资产。
