# GitHub PR Demo

This file is a minimal example used to demonstrate a pull request workflow.

Both this note and the companion script `scripts/github_pr_demo.py` are demo-only.
They are not part of the manuscript toolchain and should not be reused as production automation.

It keeps the change isolated from ongoing manuscript work and shows the full path:

- create a branch
- commit a scoped change
- push the branch
- open a draft pull request
