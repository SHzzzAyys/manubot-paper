# thesis-ready 目录说明

这个目录存放更接近学位论文可直接改写状态的章节资产。和 `docs/thesis/` 相比，这里的材料更强调：

- 章节结构完整
- 论证顺序稳定
- 能直接拆进论文正文
- 和主库数据、综述正文、情报层保持一致

## 当前文件

- `01-literature-review-draft.md`
  综述型总草稿，适合快速把握全篇结构。
- `02-chapter-background-and-significance.md`
  研究背景与意义章节包。
- `03-chapter-review-of-routes.md`
  国内外研究现状与主要路线综述章节包。
- `04-chapter-gaps-objectives-and-innovation.md`
  研究空白、研究问题、研究目标和拟创新点章节包。
- `05-citation-map.md`
  章节级引用映射表，便于后续快速落引用。
- `06-section-bridges-and-conclusion-bank.md`
  章节过渡句、总结句和收束段模板。
- `07-chapter-method-support-and-evaluation.md`
  检测标志物、活性判定方法、阶段变化研究与评价体系支撑章节包。
- `08-chapter-one-assembled-draft.md`
  第一章整章草稿，适合直接改写为学位论文初稿。
- `09-chapter-one-assembly-guide.md`
  第一章拼装说明，说明各章节包如何组合使用。

## 推荐用法

1. 如果想直接拿到一版整章草稿，优先从 `08` 开始。
2. 如果想自己拼装，则从 `02`、`03`、`04`、`07` 取材。
3. 再用 `05` 对照补参考文献。
4. 最后用 `06` 把段落和小节之间的衔接做顺。
