# thesis-ready 目录说明

这个目录存放更接近毕业论文可直接改写状态的章节资产。与 `docs/thesis/` 相比，这里的材料更强调：

- 章节结构完整
- 论证顺序稳定
- 可直接拆分进论文正文
- 与当前主库证据和正文保持一致

当前包含：

- `01-literature-review-draft.md`
  综述型总草稿，适合快速把握全篇结构。
- `02-chapter-background-and-significance.md`
  研究背景与研究意义章节包。
- `03-chapter-review-of-routes.md`
  国内外研究现状与技术路线综述章节包。
- `04-chapter-gaps-objectives-and-innovation.md`
  研究空白、研究问题、研究目标和拟创新点章节包。
- `05-citation-map.md`
  章节级引用映射表，便于后续写作时快速落引用。
- `06-section-bridges-and-conclusion-bank.md`
  章节过渡句、总结句和收束段落模板。

推荐使用方式：

1. 先从 `02`、`03`、`04` 按章节拼出你的第一版毕业论文正文。
2. 再用 `05` 对照补参考文献。
3. 最后用 `06` 把段落和小节之间的衔接做顺。
