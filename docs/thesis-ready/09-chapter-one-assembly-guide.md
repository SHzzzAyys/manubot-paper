# 第一章拼装说明

这份说明的目标很简单：让你把 `thesis-ready` 里的零散章节资产，快速拼成一版完整、顺畅、可直接改写的第一章。

## 推荐顺序

如果你想最快得到一版完整草稿，建议优先使用：

1. `08-chapter-one-assembled-draft.md`
2. `05-citation-map.md`
3. `06-section-bridges-and-conclusion-bank.md`

如果你想自己微调结构，建议按下面顺序取材：

1. `02-chapter-background-and-significance.md`
2. `03-chapter-review-of-routes.md`
3. `07-chapter-method-support-and-evaluation.md`
4. `04-chapter-gaps-objectives-and-innovation.md`
5. `06-section-bridges-and-conclusion-bank.md`
6. `05-citation-map.md`

## 最省事的用法

如果你现在只是想尽快有一版可提交给导师或继续润色的文本，最省事的方式是：

1. 直接以 `08-chapter-one-assembled-draft.md` 为底稿。
2. 用 `05-citation-map.md` 给每一小节补文献。
3. 用 `06-section-bridges-and-conclusion-bank.md` 调整语气和衔接。
4. 最后按你的学校格式统一标题层级和参考文献样式。

## 使用提醒

- `08` 是整章草稿，适合直接改写。
- `02`、`03`、`04`、`07` 更适合作为补料来源。
- `05` 负责“这一段更适合配哪些文献”。
- `06` 负责“这一段和下一段怎么接得更自然”。
