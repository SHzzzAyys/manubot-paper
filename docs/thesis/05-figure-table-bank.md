# 图表与材料方案库

本文件用于提前规划毕业论文、开题汇报和答辩中最值得制作的图表。

## 图 1：猫弓形虫传播链与疫苗干预位置示意图

目的：
- 用一张图说明猫为何是终末宿主疫苗的核心切入点。

内容建议：
- 猫摄入包囊或组织中的寄生虫
- 肠道有性生殖
- 卵囊排出进入环境
- 土壤、水源、食物链、人群和家畜暴露
- 疫苗干预位置标在“猫肠道阶段/卵囊排出环节”

适用场景：
- 论文第一章
- 开题答辩第一页背景图

## 图 2：猫弓形虫疫苗研究路线演化图

目的：
- 用时间轴展示研究从基础免疫到减毒株、黏膜免疫、分子平台的发展。

内容建议：
- 1982：基础免疫与再排卵囊认识
- 1991-1993：T-263 概念验证
- 2007-2017：rhoptry / rROP2 / 黏膜免疫
- 2019-2020：HAP2 KO 与 Mic1-3KO
- 2025-2026：ROP18、GRA12、PruΔpp2a-c

适用场景：
- 文献综述章节
- 答辩中的“研究现状”部分

## 图 3：不同技术路线优缺点对比图

候选点：

适用场景：
