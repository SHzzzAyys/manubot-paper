# 毕业论文写作资产库

本目录用于沉淀可直接服务毕业论文写作、开题答辩、盲审回复和后续论文扩展的高复用材料。

## 目录说明

- `01-chapter-background-significance.md`
  可直接参考的“研究背景与研究意义”章节草稿。
- `02-chapter-review-status.md`
  可直接参考的“国内外研究现状”章节草稿。
- `03-chapter-gaps-objectives.md`
  可直接参考的“研究空白、研究问题与研究目标”章节草稿。
- `04-paragraph-bank.md`
  高复用段落库，适合直接改写后进入毕业论文正文。
- `05-figure-table-bank.md`
  图表方案库，适合做论文图、开题汇报图和答辩图。
- `06-gap-matrix.md`
  研究空白矩阵的可读版。
- `07-defense-and-review-qa.md`
  答辩和盲审高频问题及回答模板。

## 使用建议

1. 先读 `01` 至 `03`，搭建毕业论文文献综述主线。
2. 从 `04` 中选取需要的段落，结合自己的课题对象进行改写。
3. 从 `05` 中挑选图表方案，作为开题、论文或答辩的内容框架。
4. 用 `06` 明确研究空白与课题切入点。
5. 用 `07` 提前准备答辩和盲审问答。

## 当前定位

这些材料并不是“自动可直接提交”的最终毕业论文正文，而是已经尽量写到“可直接引用、可直接改写、可直接扩展”的状态。
如果后续明确你的毕业论文题目、研究对象和实验设计，可以进一步把这些通用资产压缩成更贴近你本人课题的定稿版本。
