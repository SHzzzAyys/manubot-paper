# 研究空白矩阵

| 研究空白 | 现有证据现状 | 主要限制 | 适合形成的课题切入点 |
| --- | --- | --- | --- |
| 评价体系不统一 | 不同研究在猫只数、攻毒虫株、剂量、采样窗口和卵囊计数方法上差异明显 | 难以横向比较、难以形成标准证据链 | 标准化猫攻毒评价体系构建 |
| 免疫机制不清 | 多数研究报告抗体或细胞因子变化，但与卵囊终点关联不足 | 体液指标与传播阻断结局脱节 | 肠道黏膜免疫和局部细胞免疫机制研究 |
| 长期保护不足 | 自然感染后的抗再排卵囊保护会衰减 | 难以支持长期应用价值判断 | 长期随访和加强免疫策略研究 |
| 异源保护不足 | 异源再感染更容易再次诱发排卵囊 | 现有研究多基于同源或单次挑战 | 多基因型虫株条件下的保护评价 |
| 亚单位路线保护有限 | rhoptry、rROP2、rGRA12、ROP18 等多表现为部分保护 | 保护幅度不够稳定 | 多抗原联合设计、佐剂优化、递送系统优化 |
| 减毒株转化障碍大 | T-263、HAP2 KO、PruΔpp2a-c 路线保护潜力较高 | 安全性、稳定性、监管与放大问题突出 | 减毒株安全性评价和可控性优化 |
| 文献层证据碎片化 | 单篇研究样本量小、设计异质性大 | 难形成统一叙述框架 | 证据分级、结构化证据库与研究矩阵构建 |

## 可直接用于论文的概括句

“现有猫弓形虫疫苗研究的核心矛盾并不在于是否存在候选路线，而在于不同路线分别受限于评价体系不统一、保护机制不清、长期与异源保护证据不足，以及保护强度与转化可行性难以兼顾等问题。”  

“因此，未来研究的重点不应仅放在新抗原的不断累积上，而应更多聚焦于标准化评价体系、肠道黏膜机制、长期与异源保护，以及高保护路线的转化可行性优化。”
