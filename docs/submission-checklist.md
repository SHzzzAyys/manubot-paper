# 投稿准备清单

本清单面向当前综述《猫的弓形虫疫苗研究进展》，用于在正式投稿前逐项核对正文、补充材料和基础信息。

## 一、题名页与作者信息

- [ ] 在 `content/metadata.yaml` 中补全作者单位。
- [ ] 核对通讯作者邮箱、姓名拼写和作者顺序。
- [ ] 如目标期刊要求，补充 ORCID。
- [ ] 根据目标期刊要求确认中英文题名、摘要和关键词格式。

## 二、正文结构

- [ ] 核对摘要是否包含研究背景、主要技术路线、核心结论和未来方向。
- [ ] 核对引言是否充分说明猫作为终末宿主的 One Health 意义。
- [ ] 核对结果部分对关键原始研究的描述是否与原文一致。
- [ ] 核对讨论部分是否避免过度推断，且清楚区分证据等级。
- [ ] 核对结论与展望是否与全文证据强度保持一致。

## 三、图表与补充材料

- [ ] 确认表 1 至表 5 的编号、表题和字段名称统一。
- [ ] 确认 `content/10.supplementary-notes.md` 中的缩略词说明覆盖所有表格。
- [ ] 确认补充表与正文引用的文献信息一致。
- [ ] 如目标期刊要求独立补充文件，决定表 5 和补充材料说明的拆分方式。

## 四、文献与事实核对

- [ ] 再次复核近一年论文是否完整纳入。
- [ ] 再次抽查关键原始研究的样本量、免疫程序、攻毒条件和卵囊数据。
- [ ] 检查正文和表格中是否存在过度绝对化表述。
- [ ] 对仅依据摘要或期刊页面可见信息引用的研究做特别标记。

## 五、格式与导出

- [ ] 运行 `manubot process` 检查章节顺序和引用纳入是否正常。
- [ ] 如需 HTML/PDF 导出，先补齐 `pandoc-fignos` 等缺失依赖。
- [ ] 确认目标期刊是否要求 Word、PDF 或 LaTeX 版本。
- [ ] 检查中英文标点、数字写法和缩略词首次出现格式。

## 六、投稿策略

- [ ] 确定目标期刊和投稿语言。
- [ ] 根据期刊要求决定主文长度和补充材料范围。
- [ ] 准备投稿信、亮点摘要或图形摘要（如期刊要求）。
- [ ] 预留一轮给导师或合作者内部审阅。
