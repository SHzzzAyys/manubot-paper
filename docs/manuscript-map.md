# 文稿结构地图

当前综述稿的内容组织如下：

- `content/01.abstract.md`
  用于摘要。
- `content/02.introduction.md`
  用于研究背景、One Health 意义和研究问题提出。
- `content/03.methods.md`
  用于说明文献检索范围、纳入标准和证据组织方式。
- `content/04.results.md`
  用于按技术路线和时间脉络展开代表性研究结果。
- `content/05.discussion.md`
  用于解释瓶颈、证据分级、转化问题和未来方向。
- `content/06.core-table.md`
  用于主文核心比较表。
- `content/07.timeline.md`
  用于阶段性研究演化时间轴。
- `content/08.conclusion.md`
  用于结论与展望。
- `content/09.study-matrix.md`
  用于逐篇研究矩阵。
- `content/10.supplementary-notes.md`
  用于补充材料表注、缩略词和数据口径说明。

推荐的投稿分工如下：

- 主文保留：
  `01`、`02`、`03`、`04`、`05`、`08`
- 正文或主文补充信息：
  `06`、`07`
- 补充材料：
  `09`、`10`

如果后续按期刊模板拆文件，优先保持这一层级关系不变，只调整显示位置和标题样式。
